# Product Thesis

## What We Are Building

We are building an agentic clinical workspace: a chat-first environment where a clinical agent can operate over a patient context package, call approved tools, maintain durable project state, and update structured side panes while the user steers the work.

The first production-shaped workspace is Trial Finder.

The user should feel like they are working with an accountable clinical operations assistant, not browsing a static web app and not watching a hidden black-box agent.

## What The Workspace Is Not

- not a generic FHIR browser
- not a patient portal
- not a static dashboard
- not a one-shot chatbot
- not a demo flow that only works through deterministic stubs
- not arbitrary agent-generated HTML

## North Star

The agent helps manage a real clinical-trial pursuit end to end:

1. understand what the patient/user is looking for
2. search approved trial sources
3. explain match and mismatch criteria
4. let the user select trials worth pursuing
5. create a pursuit record
6. prepare outreach or application packets
7. track submission and follow-up
8. preserve evidence, citations, and decisions

## Experience Principle

Chat is the command surface. The canvas is the work surface. The inspector is the trust surface. The management board is the durable state surface.

All four are part of one workspace.
