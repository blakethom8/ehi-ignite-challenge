## Recently Implemented Locally

### Publish Chart

- Published snapshot records now carry activation metadata and change summaries against the prior active snapshot.
- Publish Chart shows active-snapshot state, latest-run deltas, snapshot-history deltas, and rollback confirmation with current/target snapshot counts.
- Prior snapshots remain available for rollback/audit.

### Labs v2

- Key Labs API now returns derived reference range labels, abnormality direction, alert severity, and per-history-point status where configured thresholds are available.
- Labs page now has status filters, reference/status table columns, flagged trend points, and a richer detail card.
- Labs remains scoped to the active published chart snapshot.

### Review Queue -> Source Intake

- Source review items route reviewers back into Source Intake with the affected staged file highlighted.
- Source Intake shows a source-fix callout and instructs the reviewer to repair/extract, re-run harmonization, then publish.

### Clinical Notes

- Published clinical notes now have a first-class patient endpoint: `/api/patients/{patient_id}/clinical-notes`.
- History has a Notes tab with search, source/author metadata, encounter-link context, previews, and full-note expansion.
- Encounter timeline/detail responses include linked clinical-note counts and note snippets.
- Care Journey includes clinical notes as a timeline section, grouped by document type and clickable into a full note detail pane with source/encounter provenance.

### Provider / Site / Encounter Semantics

- Encounter responses now carry derived specialty, source category, and provenance labels.
- History and Care Journey can better distinguish office visits, source document events, lab/diagnostic events, and other document-derived timeline rows.
- Harmonization artifacts preserve PractitionerRole displays/specialty labels when FHIR provides them.
