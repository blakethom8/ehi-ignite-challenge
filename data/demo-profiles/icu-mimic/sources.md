# cb70e6ae — Document Sources

Six synthetic documents complement the FHIR Bundle, each authored as if it came from a different real-world source the patient encounters: hospital, anticoag clinic, EP lab, sleep clinic, pre-op intake, outside oncology provider. Together they simulate the kind of mixed-provenance chart an Atlas user would actually receive.

All documents were generated by `scripts/synthesize_documents.py` using the FHIR Bundle as ground truth.

## Deliberate inconsistencies (the demo wedge)

These are intentional — they exist to give the demo something concrete to resolve on screen.

### 1. Apixaban "stopped" vs. still active

- The **pre-op anesthesia questionnaire** has the patient writing in his own words that he STOPPED apixaban "about 2 weeks ago."
- The **anticoag clinic letter** and the **discharge summary** both show him as actively on apixaban 5 mg BID, with no documented hold.
- **Why this matters:** if the questionnaire is true the surgery proceeds with less bleeding-risk concern; if the structured chart is true, bridging plan changes entirely. The 30-second answer for the surgeon is "the chart and the patient's self-report disagree — verify in person before incising."

### 2. CLL "completed" outside vs. "not in remission" in-house

- The **outside oncology C-CDA** from Dana-Farber lists CLL with status `completed` and a note that the patient "achieved complete response after FCR regimen."
- The **in-house FHIR record** still codes CLL as "Chronic lymphocytic leukemia of B-cell type **not having achieved remission**."
- **Why this matters:** active vs. remitted CLL changes peri-op infection-risk planning, transfusion thresholds, and follow-up cadence. Either the outside record is stale or the in-house code is stale — Atlas should surface that both records exist and disagree.

### 3. CLL clinicalStatus "remission" (structured outside FHIR) — twin of #2

- The **outside oncology FHIR Bundle** from Dana-Farber codes the CLL Condition with `clinicalStatus = remission` — the structured-data twin of the C-CDA narrative.
- The in-house record still codes CLL as **active**.
- **Why this matters:** harmonization can match the same concept by code system + identifier across systems and surface that the *structured* clinicalStatus disagrees. Tests the platform's "same Condition, different status across sources" resolution path.

### 4. Missing IBRUTINIB in the in-house chart

- The **outside oncology FHIR Bundle** lists an active `MedicationStatement` for **ibrutinib** (RxNorm 1442968).
- The in-house chart contains NO ibrutinib reference anywhere — not in MedicationRequest, MedicationAdministration, or MedicationStatement.
- **Why this matters:** the outside oncologist started the patient on ibrutinib but the news never reached the inpatient team. Ibrutinib has serious bleeding/drug-interaction implications, especially layered on top of apixaban. Harmonization should detect the *outside-only* medication and flag it as a gap in the in-house list.

## How to regenerate

```bash
uv run python scripts/synthesize_documents.py --persona icu-mimic
uv run python scripts/synthesize_documents.py --persona icu-mimic --doc preop_anesthesia_questionnaire --force
```

Raw HTML used to render each PDF is cached at `documents/_cache/<name>.html`.
