# `archive/design-miro/`

The pre-Atlas design system. Miro-inspired: Blue 450 (`#5b76fe`), Roobert PRO Medium, pastel accent palette, beige/cream surfaces, generous radii (8–50px).

Replaced wholesale by the **Atlas Agentic Workspaces** design system in May 2026 — every token, every color, the full font stack:

- New surfaces: cool paper-white (`--bg-app: #eef2f6`), no beige
- New action color: clinical blue (`--action: #1d4ed8`)
- New typography: Inter Tight + IBM Plex Mono + Source Serif 4
- New spacing scale (4/8/12/16/20/24/32) and tighter radii (4/6/10/pill only)
- Dark navy chrome (`--chrome-modulebar`, `--chrome-titlebar`) constant across themes
